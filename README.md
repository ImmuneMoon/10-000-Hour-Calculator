A calculator for working out how long you have left to reach 10,000 hours in a skill. Enter how many hours a day you practice, how many days a week (7 if left blank), and how long you've been practicing in months and years.

- Live site: [immunemoon.github.io/10-000-Hour-Calculator](https://immunemoon.github.io/10-000-Hour-Calculator/)

## Built with

- HTML, CSS and JavaScript
- [Bootstrap](https://getbootstrap.com/)
- [jQuery](https://jquery.com/)
